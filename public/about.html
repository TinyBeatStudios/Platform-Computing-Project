About Us!

My!Library is a group project built by three very Talented and Handsome CS students. A web app for tracking your personal book collection digitally!

The Project:

My!Library lets you manage your personal book collection online! You can add books by searching Google Books (or entering them manually), track your reading status, write personal notes, or even build a wishlist of books you want to read next! That's crazy cool!

Everything is saved to a real database using MySQL. Just sign up once and your library is there every time you come back! (assuming you ave MySQL installed that is, hehe)

HTML Tailwind CSS JavaScript jQuery Node.js Express.js MySQL Google Books API
